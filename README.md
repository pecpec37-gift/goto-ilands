# 🏝️ 五島列島クイズ道場

五島列島旅行前の予習に最適な4択クイズゲームです。  
ブラウザだけで動作し、インストール不要・サーバー不要です。

## 🎮 遊び方

1. TOPページでジャンルを選ぶ
2. プレイヤー名を入力してスタート（入力しなくてもOK）
3. 120秒以内に10問を解く
4. 残り時間がボーナス点に加算！
5. 結果画面で「スコアを登録する」→ この端末にスコアが保存される
6. 「🏆 ランキングを見る」でジャンル別Top20を確認

## ⚙️ ルール

| 項目 | 内容 |
|------|------|
| 制限時間 | 120秒 |
| 出題数 | 各ジャンル10問（ランダム） |
| 正解 | +10点 ＋ 残り時間+5秒 |
| 不正解 | 減点なし・残り時間−5秒 |
| ボーナス | 残り時間がそのまま加算 |

## 📚 ジャンルと問題数

| ジャンル | 問題数 |
|----------|--------|
| ⛪ 歴史（キリシタン文化・幕末） | 35問 |
| 🗺️ 地理（島の名前・地形・交通） | 30問 |
| 🍜 特産品（食べ物・工芸・産業） | 35問 |
| 🌊 観光スポット（景勝地・教会） | 35問 |
| **合計** | **135問** |

毎回ランダムに10問が選ばれるので、繰り返し楽しめます。

## 🏆 ランキングについて

- スコアはこの端末のブラウザ（localStorage）に保存されます
- 同じ端末で複数人が遊ぶ場合は、プレイヤー名を変えてプレーするとそれぞれの記録が残ります
- ジャンルごとにTop20件を保存
- 「🗑️ このジャンルの記録を削除」ボタンでリセット可能

## 🚀 GitHub Pages でのデプロイ方法

```
1. GitHubで新規リポジトリを作成（例: goto-quiz）
2. index.html と README.md をアップロード
3. Settings → Pages → Source: Deploy from branch → main / (root)
4. 数分後に公開URLが発行される
   → https://your-username.github.io/goto-quiz/
5. URLをLINEやSNSで友人に共有
```
